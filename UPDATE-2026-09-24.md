# Bonanzbar-Update vom 24.09.2026

Basis: `blackbyte9/bonanzbar-online`, main-Commit `a61c2df` (zu Beginn dieser Änderung von GitHub abgerufen). Dieses Paket enthält nur die geänderten und neuen Dateien für diesen Stand. Vorhandene Konten und Daten bleiben erhalten. Keine SQL-Migration und keine erneute Ersteinrichtung notwendig.

## Einspielen

1. ZIP entpacken.
2. In GitHub `blackbyte9/bonanzbar-online` öffnen und main auswählen.
3. `Add file` → `Upload files`.
4. Den Inhalt des entpackten Ordners hochladen: `api`, `server`, `src`, `public`, `tests` und diese Update-Anleitung. Nicht den äußeren ZIP-Ordner hinzufügen.
5. Änderungen speichern. Bei automatisch verbundenem Vercel-Projekt die neue Veröffentlichung unter Deployments prüfen.
6. Nach erfolgreicher Veröffentlichung die App einmal ohne Anmeldung in einem privaten Browserfenster und einmal als Admin/Master testen.

Kein Reset, kein erneutes `npm run bootstrap`, keine Änderung an Auth-Schlüsseln oder Supabase-Konfiguration.

## Änderungen

- Ohne Anmeldung ist jetzt das Veranstaltungsprogramm erreichbar, inklusive Bandinfos, Bildern, Band-Homepage, YouTube, Tickets und veröffentlichten Konzertrückblicken. Über „Anmelden“ gelangt man zur bisherigen Anmeldung.
- Die neue öffentliche API gibt ausschließlich ausdrücklich ausgewählte Veranstaltungsfelder und veröffentlichte Rückblicke aus. Crew-Notizen, Bewerbungen, Profile, Social Wall und Finanzdaten sind nicht Bestandteil dieser öffentlichen Ansicht.
- Hellerer brauner Kopfbereich und hellere braune Kacheln mit roten Überschriften (Braun: #705044). Der Bonanzbar-Schriftzug steht mittig, auch auf dem Handy. Das bestehende Logo wird per CSS ohne sichtbare weiße Hintergrundfläche in den braunen Balken eingeblendet.
- Admin → Ansicht wechseln: schreibgeschützte Vorschau als Crew, Mitglied, Gast oder Admin. Master kann zusätzlich die Master-Ansicht prüfen. Die tatsächliche Kontorolle wird nicht geändert. Persönliche Listen zeigen ggf. die eigenen Daten, nicht die Daten eines fremden Mitglieds.
- In jeder Veranstaltungsansicht gibt es einen aufklappbaren RÜCKBLICK-Button im Stil eines Konzerttickets. Bei Veranstaltungen mit veröffentlichtem Rückblick ist dieser zusätzlich direkt an der Veranstaltung sichtbar.
- Rückblicke bearbeiten Admin und Master weiterhin über die Verwaltung. Im Master-Buchhaltungsbereich gibt es einen direkten Zugang zur Rückblick-Bearbeitung. Entwürfe werden nicht öffentlich ausgegeben.
